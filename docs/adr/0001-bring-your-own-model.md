# Bring your own model through an OpenAI-compatible connection

Related Terms are generated by an AI model the user chooses, connected through a single OpenAI-compatible form (server address, API key, model name) with presets for popular providers, instead of a model built into the extension. This keeps the extension open to any provider, including cheap ones like DeepSeek and local models via Ollama or LM Studio, and means we never run or pay for model access ourselves.

## Consequences

Models can't be assumed to search the web, so the extension collects background material itself (Wikipedia, Fandom wiki, the topic's subreddit) and passes it to the model; see [ADR-0002](./0002-local-matching-against-ai-built-term-list.md).
