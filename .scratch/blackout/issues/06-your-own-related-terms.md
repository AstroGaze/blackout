# 06: Your own Related Terms

**What to build:** The user can add their own Related Terms to any Protected Topic. They are Strong by default, can be marked as a common word (Weak), are shown without spoiler warnings, and are kept separate from AI-generated terms so later refreshes never touch them.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] Settings page lets the user add and remove their own terms per topic
- [ ] User terms are Strong by default; a "this is a common word" option makes one Weak
- [ ] User terms are listed without any spoiler warning
- [ ] Stored terms record whether the user or the AI added them
- [ ] A newly added user term takes effect on open pages immediately
