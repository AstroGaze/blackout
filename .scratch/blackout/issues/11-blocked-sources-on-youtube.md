# 11: Blocked Sources on YouTube

**What to build:** The user can block a YouTube channel so everything it posts is hidden whatever its title says, from a "Block this source" option on any video or comment, and manage the list in settings. Blocked Sources apply whichever topics are active.

**Blocked by:** 03, 05

**Status:** ready-for-agent

- [ ] "Block this source" is available on video tiles, Shorts and comments, including on Hidden Items
- [ ] Content from a Blocked Source is hidden with a "Blocked Source" label
- [ ] Settings list Blocked Sources (site + account) and allow unblocking
- [ ] Blocked Sources apply whenever at least one topic is active
- [ ] Page-seam tests cover a blocked channel's tiles and comments
