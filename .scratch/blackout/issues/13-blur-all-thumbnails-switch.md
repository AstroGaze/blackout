# 13: Blur-all-thumbnails switch

**What to build:** An optional switch, off by default, that blurs every YouTube thumbnail while on, as a stopgap for image-only spoilers around a launch.

**Blocked by:** 03, 05

**Status:** ready-for-agent

- [ ] Switch available in the popup and settings, off by default
- [ ] When on, all YouTube thumbnails (feed, search, Shorts, recommendations) are blurred from first paint
- [ ] Hovering or clicking a thumbnail does not unblur it without confirmation
- [ ] Turning it off un-blurs thumbnails on open pages without a reload
